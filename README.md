# Meridian Health Centre — Hospital/Medical Centre Website

A responsive 6-page hospital website built with HTML, CSS, and vanilla JavaScript for the Microtech Web Development capstone project.

## Pages
- `index.html` — Home (with FAQ accordion)
- `departments.html` — Departments overview
- `doctors.html` — Doctors directory (with department filter)
- `services.html` — Services (diagnostics, pharmacy, etc.)
- `appointments.html` — Appointment booking form
- `contact.html` — Contact form + Google Maps

## Features
- Fully responsive (mobile, tablet, desktop)
- Department filter for doctors (JavaScript)
- FAQ accordion (JavaScript)
- Front-end form validation with success message
- Embedded Google Map
- Scroll-reveal animations
- Mobile hamburger navigation
- Sticky emergency contact banner

## Tech Stack
- HTML5
- CSS3 (custom properties, Grid, Flexbox)
- Vanilla JavaScript (no frameworks)
- Google Fonts (Newsreader, Manrope)

## How to Run Locally
1. Download/unzip this folder.
2. Open `index.html` in any browser, or use VS Code's Live Server extension.
